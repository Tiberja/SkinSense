# SkinSense
Web-App 

## Setup
1. Virtuelle Umgebung erstellen & aktivieren
   + `python -m venv .venv`
   + `source .venv/bin/activate`

2. Abhängigkeiten installieren
   + `pip install -r requirements.txt`

3. Datenbank initialisieren
   + `flask init-db`

4. Beispieldaten einfügen
   + Im Browser: `http://127.0.0.1:5000/insert/sample`

5. Start
   + `flask run` 
   + oder `flask --app app run`
